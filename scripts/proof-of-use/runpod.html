Workload

Code: scripts/corners/run-batch.ts
Notes: runpod/README.md

Kotak turns any job into six skill corners and asks twelve yes/no questions about them. RunPod generates that content once, ahead of time, for every one of the 923 O*NET occupations. There is no custom handler: the stock RunPod vLLM worker serves the model. This is Kotak's only GPU work: the live app calls the Claude and ElevenLabs APIs (Technical Declaration, sections 3 and 4). 

+-------------+    +---------------+    +====================+    +-----------+    +-------------------+
| O*NET tasks |--->| prompt+schema |--->| Qwen3.8-27B · H100 |--->| validator |--->| role-corners.json |
+-------------+    +---------------+    +====================+    +-----------+    +-------------------+
   923 jobs         1 request each        RunPod Serverless        3 tries max       radar, roadmap
  1. 01InputThe job's title, description and O*NET tasks, grouped by work activity into at most six groups by fixed rules, with no AI.
  2. 02AskThe model groups the tasks into six named corners and writes three can-do statements per corner (basic, working, advanced), with learning hours, SDG targets and search-link resources.
  3. 03ConstrainA strict JSON schema goes in response_format; vLLM's structured outputs make every token follow it.
  4. 04CheckA validator rejects any answer that drops a task, puts a task in two corners or cites a task the job does not have.
  5. 05RetryA rejected answer goes back to the model with its errors. Seven were regenerated; none failed.
  6. 06Writedata/generated/role-corners.json feeds the check-up questions, the Future Skills Radar and the roadmap; role-corners-run.json records every run.

Example request

Endpoint settings:
runpod/README.md

request.shPOST /openai/v1/chat/completions
curl https://api.runpod.ai/v2/5yjk19uqmrpbp7/openai/v1/chat/completions \
  -H "Authorization: Bearer $RUNPOD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3.8-27B-FP8",
    "messages": [{"role": "user", "content": "Name one skill of a graphic designer as JSON."}],
    "temperature": 0,
    "max_tokens": 50,
    "chat_template_kwargs": {"enable_thinking": false},
    "response_format": {"type": "json_schema", "json_schema": {"name": "skill", "schema": {
      "type": "object", "properties": {"skill": {"type": "string"}},
      "required": ["skill"], "additionalProperties": false}}}
  }'
rerun.shRUNPOD_API_KEY and RUNPOD_ENDPOINT_ID set
