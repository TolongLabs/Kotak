2.Project Description [Maximum 250 words]

246 of 250 words

Kotak shows a Malaysian worker which of their skills are rising or declining with AI, and gives them a dated, cited plan for what to learn next. It serves SDG 4, target 4.4: more youth and adults with relevant skills for decent jobs.

In 2024, 39.8% of Malaysians aged 15 and over had above-basic digital skills in all five areas (UN SDG indicator 4.4.1). 56% of Malaysian professionals use AI tools at work, but only 26% have had formal training (Hays Asia Salary Guide 2025). Workers get static skills lists with no dates, no scores and no plan.

Kopi, a cat counsellor, asks where the user is now, what they studied and what they want, then 12 questions about their job or target role. Kotak draws a Future Skills Radar of the job's 6 core skills, each with a verdict (Rising, Steady, Declining, Split or Unknown) and its dated sources. It ranks up to 6 roles by a fit score that shows its sum. It builds an ordered roadmap with each step's hours, one free resource and its SDG targets. It covers 923 jobs, in English, Malay and Chinese.

Fixed rules over dated public data set every verdict, score and step: the Anthropic Economic Index for Malaysia (April and May 2026), DOSM Job Market Insights and O*NET 30.1. AI only does language work, and a verifier rejects any explanation that changes a verdict. When May's data replaces April's, verdicts change and What Changed lists each one.

3.1.Final System Architecture

Provide a detailed description (and, if possible, an attached technical diagram) of your fully built system. Explain how your application integrates GenAI APIs, database structures, and backend/frontend frameworks into one unified solution.

Kotak is one TypeScript monorepo on Bun. The core rule: the data decides; the AI explains. No engine function calls a model, and no model output can change a number (docs/algorithm-card.md).

  • Frontend: React 19, Vite and Tailwind CSS, with Recharts for the radar, three.js for the 3D space of all 923 jobs and Live2D for Kopi. The rule engine, @kotak/sdk, runs in the browser over a static bundle of dated JSON snapshots, one file per job, each Zod-checked at build time. A check-up needs no server, so it still works when every API is down.
  • Backend: a Hono API, the same build on Bun (Replit) and on Cloudflare Workers, with a KV response cache and one Durable Object for chat and MCP. Every route validates its request and response with Zod.

  • GenAI APIs: Claude Haiku 5.5 matches a job title typed in any language to an O*NET job, which the user confirms; explains verdicts and the What Changed summary; runs Ask Kopi, an agent with 8 read-only tools that compute every number with the engine; and judges a certificate uploaded as proof of a roadmap step. A. The rules that set every number (packages/shared/src/rules/, excerpts)

// scoring.ts: level 0 to 3 from the basic and advanced answers (1 to 4)
export function cornerLevel(basic: Rating, advanced: Rating): number {
  return (1.5 * (basic - 1)) / 3 + (1.5 * (advanced - 1)) / 3
}
/** fit_score = sum(min(user_level, target_level)) / sum(target_level) * 100, with the maths exposed. */
export function fitScore(corners: { corner_id: string; user_level: number; target_level: number }[]): FitScore {
  const terms = corners.map((c) => ({ ...c, term: Math.min(c.user_level, c.target_level) }))
  const numerator = terms.reduce((sum, t) => sum + t.term, 0)
  const denominator = terms.reduce((sum, t) => sum + t.target_level, 0)
  return { score: (numerator / denominator) * 100, numerator, denominator, terms, is_estimate: true }
}
// verdicts.ts: the 5-row verdict table. Null (shown as Unknown) when an input is missing.
export function verdictRow(trend: AiTrend, mode: CollaborationMode, demand: DemandState): VerdictRow | null {
  if (trend === 'unknown') return null
  if (trend === 'rising') {
    if (mode === 'unknown') return null
    return mode === 'augmentation' ? 'Rising: AI helps it scale' : 'Declining because of AI'
  }
  if (demand === 'up') return "Rising: AI can't do it yet"
  if (demand === 'flat') return 'Steady'
  if (demand === 'down') return 'Declining for other reasons'
  return null
}
// trend is 'rising' when the projected 12-month change is above RISING_THRESHOLD = 0.05; the projection is a
// least-squares line through the dated points, and is null (Unknown) with fewer than 2 dated points.
/** target = clamp(2.0 + ai_effect + demand_effect, 1.0, 3.0). Shrinking or unknown AI use adds no AI effect. */
const growth = Math.max(0, projection?.change ?? 0)
const size = growth / (growth + AI_EFFECT_HALF_GROWTH)          // AI_EFFECT_HALF_GROWTH = 0.5
const ai_effect = mode === 'unknown' || size === 0 ? 0 : mode === 'augmentation' ? size : -size

In formulas: level = (basic + advanced − 2) ÷ 2; fit = Σ min(level, target) ÷ Σ target × 100; target = clamp(2 + ai_effect + demand_effect, 1, 3), with demand_effect +0.5 up, 0 flat, −0.5 down. The fast future moves Malaysia halfway to Singapore's AI use index: (0.87 + ½ × (5.81 − 0.87)) ÷ 0.87 = 3.84 times the growth on May 2026 data (docs/algorithm-card.md). This is why April data gives Unknown: one dated point fits no line, so verdictRow gets 'unknown' and returns null.
