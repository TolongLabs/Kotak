## GLM-5.3 on RunPod

At 10:54 AM on 23 October, forwarded in `#📢│runpod`: Z.ai's GLM-5.3 is live as a RunPod public endpoint and the RunPod credits cover it, "entirely optional". Try it without code under Console › Hub › Public Endpoints › GLM-5.3 › Playground, or through the OpenAI-compatible API at `https://api.runpod.ai/v2/b1dd8hy2hqo1nb/openai/v1` with model `glm-5.3` and a `RUNPOD_API_KEY`. It costs $0.77 per 1M input tokens, $2.42 per 1M output tokens and $0.143 per 1M cached input tokens; keep `reasoning_effort` low and cap `max_tokens`. "Your GitHub repo gets reviewed. Keep the key in an environment variable or Replit Secrets, never in the code." Ask for more credits in `#✉️│open-ticket`, saying what you're building and why.
