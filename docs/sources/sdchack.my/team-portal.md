### Workshops

Added on 20 October. Each card has a **Join on Zoom** button and the meeting ID and password, left out here. Both workshops are on Wednesday 21 October 2026; the [Discord announcement](/docs/sources/discord.com/announcements.md#workshops-on-21-october) lists the same two.

**How to Build An App with Replit In a 20 min Time Frame**, 9:00 AM to 10:00 AM (MYT). Speaker: Sarah Li, Developer Relations at Replit.

"Turn a plain-English idea into a working app in 20 minutes. Build it with Replit Agent, improve it with AI, and publish a live link you can share with your team or judges, with no setup or coding experience needed." What participants will learn:

- **Build an app with AI**: turn a simple idea or natural language prompt into a working application using Replit.
- **Go from idea to prototype**: learn how to build without complicated setup or extensive coding experience.
- **Refine your application**: use Replit's AI-powered tools to troubleshoot, make improvements, and add features.
- **Deploy and share**: publish a working application and share a live link with teammates or hackathon judges.

**From Text to Decisions: Building AI Applications with Structured Outputs**, 10:00 PM to 11:00 PM (MYT). The portal names no speaker; the Discord announcement gives Runpod.

"Learn to choose between LLMs and specialized decision models, define classification outputs, deploy models using serverless GPUs with Python or HTTP, validate predictions and confidence scores, and manage cold starts, response times, and computing costs for reliable, efficient workflows." Key takes:

- Understand when to use a general-purpose LLM with structured outputs or a specialized decision model such as OpenJev.
- Define categories, scores, and yes-or-no outputs for classification and workflow routing.
- Use serverless GPU infrastructure and send requests with Python or HTTP.
- Interpret confidence scores and validate predictions before using them to drive actions.
- Account for cold starts, response time, and compute costs.

The card's description: many AI applications need a category, a score, or a yes-or-no decision. The session explores turning unstructured text into structured outputs for tasks such as sentiment analysis, content classification and workflow routing, from general-purpose language models with constrained outputs to specialised decision models, with OpenJev as one option. Practical Python and HTTP examples walk through deploying a model on serverless GPU infrastructure, sending requests and integrating results into an application, covering confidence scores, validation, cold starts and the trade-offs between cost and responsiveness.
