# Workshop 2 meeting chat

What the recording of SDC Hackathon 2026 Workshop 2, Replit's "How to Build An App with Replit In a 20 min Time Frame" with Sarah Li and Frederick Alexander, on 21 October 2026, preserves of the Zoom chat: the questions attendees typed that were read out in the Q&A, with their answers, and the links the hosts said they posted. The [transcript](transcript.md) covers what was said and the [slides](slides.md) what was shown. Answers are synthesised from the transcript (cited by time from the start of the organisers' recording) and the slides (cited by number).

The chat itself isn't in the recording or the workshop's [Drive folder](https://drive.google.com/drive/folders/1XmoZ-S4E0lHZDWsXfz7nMWl8Y8f0thVy): the recording is Zoom's own view of the meeting, which shows no chat panel or notifications, and no chat text appears on Sarah's shared screen. So messages are timed by when they're read out or mentioned in the recording, the askers aren't named, and questions are quoted as heard, not as typed. Questions nobody read out, and the text of the links, are lost.

**[01:13:26] Attendee** (read out by Sarah): Can you upload your code in GitHub and then import it to Replit just for publishing, deploy?

- **Answer:** Yes. Put a zip file of the code into Replit and it unpacks and deploys it; it works the other way too, and Agent can make the zip file for you (01:13:26). Publishing is shown in slides 47 and 48.

**[01:14:13] Attendee** (read out by Sarah): Can you connect Supabase to our project on Replit?

- **Answer:** Yes, or any other database provider; you just provide a Supabase API key (01:14:13).

**[01:14:30] Attendee** (read out by Frederick): Can I use Replit to generate the initial website, then download its source code to Claude to edit the remaining functions and design, then import it to Replit to publish?

- **Answer:** Yes: download the code or a zip file, work on it in Claude, ask Claude for a zip file and import it into Replit to publish (01:14:43). Replit also has connectors and MCP servers for Claude and ChatGPT, so you can build Replit apps from inside those tools (01:15:19).

**[01:16:54] Attendee** (read out by Frederick): So I can use Codex or Claude to do my project, then connect to Replit with MCP, right?

- **Answer:** Yes (01:17:04).
